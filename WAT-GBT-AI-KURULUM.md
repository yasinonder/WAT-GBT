# WAT - GBT AI | Kurulum Kilavuzu

**Kaynak dal:** `wat-gbt-ai-v1`

1. GitHub Actions sayfasindaki **WAT - GBT AI Windows x64** is akisini acin.
2. Is akisi basarili ise **Artifacts** altinda `WAT-GBT-AI-Windows-x64-portable` paketini indirin.
3. Dosyalari cikarin, portable EXE'yi ayrilmis klasorde calistirin.
4. Model servislerini ve API anahtarlarini Ayarlar'dan girin. API anahtarlari GitHub'a konmaz.
5. Veritabani entegrasyonu henuz yok; kurumsal verilerinizi bir API ile sinirli izinler uzerinden acin.

**Not:** EXE imzasizdir. Windows SmartScreen veya kurumsal BT engelleyebilir; bunlari atlamayin, gerekirse BT ekibinizden onay ve kod imzalaması alin. Derleme basarisizsa henuz indirilebilir bir Windows surumu yoktur.
